# CFAF-DDCT synthetic reference

This small, de-identified example checks the complete CFAF-DDCT training path. 
Synthetic three-class EEG-like arrays are generated by a separate script and saved under the selected data folder for inspection. The training code loads that file and performs CT channel selection, CW
weighting, feature extraction, residual attention, source pretraining, target
fine-tuning, validation-based model selection, and one locked test pass.

## Layout

```text
synthetic_data.py       in-memory synthetic EEG-like data generator
main.py                 runnable command-line entry point
cfaf_ddct/
  config.py             configuration and fixed loss weights
  data.py               seeding, split, CT/CW, and DataLoaders
  model.py              compact convolutional Transformer model
  losses.py             ICL, MMD, LMMD, CORAL, and ADVER
  train.py              in-memory source/target training loop
```

## Run

Run from this directory after installing PyTorch and NumPy. First generate the
synthetic input file:

```bash
python synthetic_data.py --output-dir outputs
```

Then run the training main function. It loads `outputs/synthetic_data.npz`
instead of generating data again:

```bash
python main.py --loss icl --epochs 200 --data-dir outputs
```

`--gamma` controls the source-sample/target-sample ratio used in each feature
adaptation step. It defaults to `1.0`, matching the original controlled
comparison protocol. To use all 15 source-domain equivalents per target
adaptation sample in this synthetic setup, use `--gamma 15`.

Transfer features are L2-normalized by default before ICL/MMD/LMMD/CORAL or
ADVER. This keeps the ICL margin numerically active instead of allowing the
raw feature norm to make every triplet satisfy the margin immediately. Use
`--no-normalize-transfer-features` only when reproducing a raw-feature
variant.

```bash
python main.py --loss icl --epochs 200 --data-dir outputs
python main.py --loss none --epochs 200 --data-dir outputs
python main.py --loss mmd --epochs 200 --data-dir outputs
python main.py --loss lmmd --epochs 200 --data-dir outputs
python main.py --loss coral --epochs 200 --data-dir outputs
python main.py --loss adver --epochs 200 --data-dir outputs
```

`none` is the classification-only control (`lambda=0`). Default adaptation
weights are ICL 0.10, MMD 0.10, LMMD 0.01, CORAL 0.05, and ADVER 0.03. ICL
uses triplet margin 1.0. MMD and LMMD use five batch-adaptive RBF kernels
with `kernel_mul=2.0`. ADVER uses gradient reversal with the standard
coefficient schedule capped at 1000 iterations.

The command prints detailed progress and exits. The synthetic input defaults
to 60 channels and 128 time samples; CT retains the 12 highest-scoring
channels, and CW applies their normalized data-derived weights.

The generator creates one target subject and 15 source subjects. Since every
subject uses the same number of trials, the total source-domain sample count
is exactly 15 times the target-domain sample count.

The target subject intentionally has a different active-channel layout,
slightly shifted class frequencies, and higher noise. The labels are still
the same three classes in both domains. This controlled shift makes it
possible to observe a non-zero feature-adaptation loss; ICL may still reach
zero later when all sampled triplets satisfy the margin.

Use another output location when needed:

```bash
python main.py --loss icl --epochs 200 --data-dir outputs --output-dir outputs/icl_subject_demo
```

During execution, the program prints all input shapes, split sizes, selected
channels, source-pretraining epochs, every target fine-tuning epoch, and the
final locked-test accuracy.
